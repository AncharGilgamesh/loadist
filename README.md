# Распределитель учебной нагрузки

Однопользовательская программа кафедры. В ней заполняют справочники, загружают учебную нагрузку из Excel, переносят часы преподавателям и выгружают индивидуальные планы и общую нагрузку.

Инструкция для того, кто работает в окне: [guide.docx](guide.docx).

Справочники дисциплин, групп, направлений и лимиты в настройках сохраняются в базе. На перенос часов они не влияют.

## Возможности

- Справочники должностей, преподавателей, рабочих таблиц, групп, дисциплин и направлений подготовки.
- Загрузка общей нагрузки из `.xls`, `.xlsx` и `.xlsm`.
- Перенос выбранных часов в рабочую таблицу преподавателя и возврат обратно, с проверкой итога часов.
- Выгрузка индивидуального плана одного преподавателя и планов всех преподавателей.
- Выгрузка общей нагрузки и статистики.
- Темы в меню «Вид»: обычная учебная, светлая и тёмная.

## Требования

- Операционная система: Windows 10.
- Python 3.11 для разработки. Код совместим с Python 3.9–3.11.
- [uv](https://docs.astral.sh/uv/getting-started/installation/) ставит Python из `.python-version` и зависимости из `uv.lock`.
- Интерфейс: PyQt5 5.15.9. На Python 3.12 и новее колёса этой версии могут не установиться.

Сервер и сеть программе не нужны.

## Установка

Команды выполняются в каталоге, где лежит `main.py`. Запуск из родительской папки ломает импорты и пути к формам, базам и шаблонам.

```text
uv sync
```

`uv sync` создаёт локальное окружение и ставит зависимости по `uv.lock`. Каталог `.venv` в репозиторий не входит.

## Запуск

```text
uv run python main.py
```

Окно называется «Распределитель учебной нагрузки».

В репозитории уже лежат учебные базы `DB/nagruzka.db` и `DB/settings.db`: вымышленные преподаватели, справочники и строка настроек. Перед работой с реальными фамилиями скопируйте оба файла в сторону. Сохранение перезаписывает строки таблицы. Базу с настоящими фамилиями в коммит не кладут.

## Структура

```text
main.py                 окно, загрузка и выгрузка Excel
HourTransfer.py         перенос часов, в том числе выбор аспиранта
KafedraRecords.py       экраны справочников кафедры
UI/                     формы Qt Designer
UICode/                 диалоги
Models/SqlHandler.py    схема SQLite и запросы
Models/ExcelHandler.py  чтение нагрузки и запись по шаблонам
Models/Models.py        таблицы Qt
Models/DataHandler.py   разбор строк, семестры, статистика, перенос строк
Data/Teacher.py         итог часов рабочей таблицы
Resources/Shablons/     шаблоны выгрузки
DB/                     базы SQLite
tests/                  проверки без окна Qt
```

Формы `.ui` загружаются при запуске. Имена виджетов в них менять нельзя: на них завязано окно.

`Resources/breeze_resources.py` и `Resources/res_images.py` сгенерированы. Их не правят и не форматируют.

## Данные

| Файл | Назначение |
| --- | --- |
| `DB/nagruzka.db` | Преподаватели, должности, группы, дисциплины, направления, рабочие таблицы |
| `DB/settings.db` | Учебный год, отделение, кафедра, лимиты, границы чтения Excel |
| `Resources/Shablons/shablon.xlsx` | Индивидуальный план |
| `Resources/Shablons/nagruzka_shablon.xlsm` | Общая нагрузка |
| `loadFileExample.xls` | Пример входящего файла |

Если в `settings` нет ни одной строки, при старте записывается строка значений по умолчанию.

Книга `.xlsx` и `.xlsm` читается с листа «нагрузка кафедры». Старый `.xls` также принимает листы «нагрузка» и «общая».

## Разработка

Зависимости приложения перечислены в `pyproject.toml` и зафиксированы в `uv.lock`. Второй список зависимостей не используется. Pytest и ruff стоят в группе dev и в поставку программы не входят.

Проверка изменённого файла:

```text
uv run ruff check путь\к\файлу.py
```

Проверка всего дерева и автоматические тесты:

```text
uv run ruff check .
uv run pytest
```

Ruff смотрит синтаксис как Python 3.9, длина строки 88. Сгенерированные файлы ресурсов из проверки исключены.

Тесты не открывают окно и не пишут в `DB/`. Они проверяют откат сохранения, чтение должности с апострофом, границу числовых колонок и пустой семестр.

Новые сообщения пользователю пишутся по-русски. Числа проверяются до преобразования в `int` или `float`. Значения в SQL передаются через `?`.

## Ограничения

- Один пользователь, одна локальная база.
- Справочники и лимиты настроек не участвуют в расчёте переноса часов.
- Установщика нет. Запуск идёт через uv из каталога с `main.py`.
