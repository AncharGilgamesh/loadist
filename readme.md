# Распределитель учебной нагрузки

Однопользовательская программа кафедры. В ней заполняют справочники, загружают учебную нагрузку из Excel, переносят часы преподавателям и выгружают индивидуальные планы и общую нагрузку.

Справочники дисциплин, групп, направлений и лимиты в настройках сохраняются в базе. На перенос часов они не влияют.

## Запуск

Для разработки нужен [uv](https://docs.astral.sh/uv/getting-started/installation/). uv берёт Python 3.11 из файла `.python-version`. Код рассчитан на Python 3.9–3.11.

Команды выполняются из папки, где лежит `main.py`:

```
uv sync
uv run python main.py
```

`uv sync` ставит зависимости по `uv.lock`.

## Файлы

- Шаблоны выгрузки: `Resources/Shablons/shablon.xlsx` (индивидуальный план) и `Resources/Shablons/nagruzka_shablon.xlsm` (общая нагрузка).
- Базы SQLite: `DB/nagruzka.db` (преподаватели, должности, группы, дисциплины, направления, рабочие таблицы) и `DB/settings.db` (учебный год, кафедра, границы чтения Excel).
- Пример входящего файла: `loadFileExample.xls`.

## Проверка изменённых файлов

```
uv run ruff check путь\к\файлу.py
```
